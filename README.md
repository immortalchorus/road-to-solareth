# Road to Solareth

A simple Three.js browser game project: a slow, atmospheric futuristic tank journey across an infinite alien landscape toward the unreachable city of Solareth.

## Status

This repository was created first so the project has a Git safety net before implementation begins.

## Planned Files

- `index.html`
- `style.css`
- `main.js`

## Run

The intended deliverable should run by opening `index.html` in a browser.
