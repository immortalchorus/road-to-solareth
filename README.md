# HoverTank©

You are a HoverTank pilot on a mission to defend a city from a maniac invader and his mecha, tanks, and spider droids.

## Status

First playable version implemented.

## Planned Files

- `index.html`
- `style.css`
- `main.js`

## Run

Open `index.html` in a browser.

The game uses Three.js from a CDN, so an internet connection is needed the first time the browser loads the library.

Optional local server:

```powershell
python -m http.server 8000
```

Then open `http://127.0.0.1:8000/`.
