# Build Prompt: Road to Solareth

This project is based on the attached Codex prompt for a simple Three.js futuristic tank exploration game.

Core target:

- Browser-playable Three.js game using `index.html`, `style.css`, and `main.js`.
- Futuristic hover-tank or tracked sci-fi tank.
- Infinite procedural alien terrain.
- Distant mythical golden city: Solareth.
- Meditative exploration with occasional light combat.
- Exact controls:
  - Up Arrow: drive forward.
  - Down Arrow: reverse.
  - Left/Right Arrow: turn tank body.
  - Shift + Left/Right Arrow: rotate turret instead of steering.
  - Spacebar: fire glowing fireballs.
- HUD with title, speed, turret angle, enemies destroyed, distance, and poetic status.
- Ambient music support with a fallback Web Audio soundscape.
